نسخه اصلاح‌شده Telegram Uploader

تغییرات:
- مدیریت ادمین با افزودن/حذف و لیست
- مدیریت مسدودی با افزودن/رفع و لیست
- تغییر زبان با ۶ زبان و منوی اصلی چندزبانه
- پیش‌نمایش متن Start از دید کاربر
- امکان ویرایش متن Start
- نمایش پنل مدیریت فایل برای ادمین هنگام باز کردن deep-link فایل/گروه
- امکان ویرایش نام فایل از پنل فایل
- بازگشت و alias های چندزبانه

Railway:
- uploader.db / Volume قبلی را حذف نکنید.
- BOT_TOKEN و سایر متغیرها را در Variables/.env تنظیم کنید.
