RAILWAY SETUP

1) Upload these files to a PRIVATE GitHub repository:
   bot.py
   requirements.txt
   Dockerfile
   railway.toml
   .gitignore
   .env.example
   uploader.db (optional seed database; keep repository PRIVATE)

2) Railway -> New Project -> Deploy from GitHub Repo.

3) Variables:
   BOT_TOKEN=YOUR_NEW_TOKEN
   ADMIN_IDS=7692023421
   PROXY_URL=
   JOIN_CHANNEL=@eldnv
   STORAGE_CHANNEL_ID=-1004384688918
   DB_PATH=/data/uploader.db
   PORT=8080

4) Add a Volume mounted at /data.

5) In Service -> Settings -> Networking -> Public Networking, Generate Domain.
   The app automatically uses https://$RAILWAY_PUBLIC_DOMAIN for generated links.

6) Deploy.

IMPORTANT:
- Do not upload .env. Put secrets in Railway Variables.
- Revoke any bot token that was exposed and use a new token.
- Leave PROXY_URL empty on Railway unless you have a real remote proxy endpoint.
- The first time the /data volume is empty, the bundled uploader.db is copied to /data/uploader.db. Existing database is never overwritten.
- The web server listens on Railway's PORT and on 0.0.0.0.
